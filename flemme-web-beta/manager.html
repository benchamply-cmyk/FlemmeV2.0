Flemme Manager

Retrouve tes échanges et le suivi des missions. Les agents sont pilotés par les administrateurs.

À qui le Manager confie les tâches

Selon la mission, le Manager utilise les capacités suivantes. Le détail de chaque tentative indique les étapes réellement effectuées.

  • Search Agent — Recherche Web : recherche des offres réelles, conserve les sources et leur date de consultation.
  • Compare Agent — Comparaison avancée : compare les tarifs et conditions disponibles, signale les avantages, exclusions et inconnues.
  • Document Agent — Analyse PDF : extrait le texte des devis PDF et documents, avec références de pages ou de blocs.
  • Quality Agent — Vérification : contrôle les citations et calculs pris en charge, signale les informations manquantes. Une validation humaine reste nécessaire.
